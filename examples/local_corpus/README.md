# local_corpus fixture

Four well-attested Tang dynasty poems, public domain in every jurisdiction,
used only to exercise `LocalReader` and the stage-2 tool layer in tests and
demos. **This is illustrative, never a finding** — it is not the development
corpus for COHORT's actual research use, which is CBETA v061
(see `docs/corpus.md`). This fixture exists so the test suite needs no corpus,
no API key and no network.
